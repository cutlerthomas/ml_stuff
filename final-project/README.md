# Blackjack AI using Double Q-Learning

A machine learning project that trains an AI agent to play blackjack using double Q-table reinforcement learning.

## What it does

- Implements a blackjack environment with standard casino rules
- Trains an AI agent using double Q-learning algorithm
- Achieves a 49-52% win rate against the dealer
- Demonstrates reinforcement learning in a probabilistic card game environment

The double Q-table approach helps mitigate overestimation bias in traditional Q-learning, allowing the agent to learn more effective blackjack strategies despite the game's inherent randomness and partial observability.
